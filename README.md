## 📌 Overview
A modern, browser-based digital photo studio built to transform and fine-tune images with speed, precision, and ease. This application offers custom styling tools, real-time lighting adjustments, and artistic canvas rendering inside a sleek dark-mode user interface.

---

## ✨ Key Features
* 🖌️ **AI Art Transformations:** Converts standard photographs into artistic digital styles.
* 🎛️ **Precision Image Adjustments:** Fine-tunes **Brightness**, **Contrast**, and **Saturation** in real time.
* 🔄 **Canvas Control:** Instant photo rotation and high-resolution output generation.
* 📱 **PWA & Mobile Ready:** Fully responsive web design, optimized for both desktop browsers and mobile installation.
